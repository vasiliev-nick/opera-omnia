# Контекст для продолжения работы

*Собрано 30 октября 2026 года.* До этого работа шла в проекте Claude «Статья по робототехнике»: переписка, память помощника
и опубликованные страницы на claude.ai. Здесь собрано всё, что из этого нужно, чтобы продолжить работу в другом месте,
например с локальной LLM, и не переспрашивать Ника о том, что он уже решил.

## Кто и зачем

**Ник** (Никита Васильев) — ML-инженер, выпускник мехмата МГУ, преподаёт курс «Practical Machine Learning», учился в художественной школе
и поэтому очень требователен к визуальному качеству. Цель — статьи по robot learning для кандидатской диссертации.

**Статья.** Тактильное восприятие формы с наблюдениями кривизны (второго порядка) в гауссовском процессе на неявной поверхности (GPIS / SDF)
и выбор касаний по качеству захвата второго порядка. Гипотезы H1–H3 (H3: выигрыш растёт с уменьшением трения). Бейзлайн — работы группы Хоффманна
(Act-VH, VISHAC). План: теория → двумерный прототип на CPU → 3D (YCB + Taxim или TacSL). Полное описание: `notes/backup/paper_backup.md`
(и PDF рядом), формальная постановка 2D-прототипа: `notes/2d_prototype_setup.md`, исходная сводка первого чата: `notes/robot_learning_project_summary.md`.

**Книги.** 5 октября Ник решил, что прежде чем ставить эксперименты, он должен понимать всю математику статьи настолько, чтобы самому преподавать её студентам.
Поэтому сейчас основная работа — учебник (главы ∅, ∇, ∠, 𝒩, ⊥) и мини-учебники на отдельные темы. Книги публичные, под именем Ника.

## Что где лежит

| Путь | Что это |
|---|---|
| `AGENTS.md` | Короткая входная точка для любого агента. |
| `CONTEXT/rules.md` | Правила Ника: как учить, как писать книги, как отвечать в чате, код, рисунки. **Самое важное.** |
| `CONTEXT/state.md` | Состояние каждой книги, что дальше, открытые вопросы. |
| `CONTEXT/workflow.md` | Сборка, проверки, нумерация, перекрёстные ссылки, общая страница, публикация на GitHub. |
| `CONTEXT/memory/` | Выгрузка памяти помощника Claude как есть (английский, краткие записи с датами). Источник для `rules.md` и `state.md`. |
| `textbook/FORMAT.md` | Единый формат всех книг: цвета, кнопки, нумерация, блоки, текст, рисунки. |
| `textbook/` | Главы основного учебника (`ch*.html`), их исходники (`src_*/`, в каждом `NOTES.md`), общий слой оформления `kit/`. |
| `minibooks/` | Мини-учебники: `cross_entropy/` (готов), `optimizers/` (§1–§11 из 16), `value_of_information/PLAN.md` (черновик плана), `FUTURE.md` (список будущих книг). |
| `notes/` | Заметки по статье и её полное резервное описание `notes/backup/`. |
| `index.html` | Общая страница всех книг с поиском. |

## Как начать с новым помощником

Дай ему этот репозиторий (или хотя бы `AGENTS.md`, `CONTEXT/*.md`, `textbook/FORMAT.md` и `notes/backup/paper_backup.md`) и такой первый запрос:

> Я Ник, ML-инженер и выпускник мехмата МГУ, пишу статью по robot learning для кандидатской: тактильное восприятие формы с наблюдениями кривизны
> в гауссовском процессе на неявной поверхности и выбор касаний по качеству захвата второго порядка. Чтобы понимать всю математику статьи,
> я пишу учебник и мини-учебники; они лежат в этом репозитории. Прочитай `AGENTS.md` и всё, на что он ссылается, особенно `CONTEXT/rules.md`
> и `textbook/FORMAT.md`, и продолжи с места, описанного в `CONTEXT/state.md`. Пиши по-русски.

## Чего здесь нет

- Переписки целиком. Всё важное из неё переписано в правила и состояние; формулировки Ника приведены там, где они задают правило.
- Опубликованных страниц claude.ai (артефактов). Их полные копии — HTML-файлы в репозитории; ссылки на артефакты в книгах и в `CONTEXT/memory/` откроет только Ник.
- Исходников шапки README (`branding/` в проекте): итоговая картинка уже лежит в `assets/banner.png`.
