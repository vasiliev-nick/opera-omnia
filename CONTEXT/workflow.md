# Как собирать, проверять и публиковать книги

## Что нужно на компьютере

- Python 3 (для миниатюр рисунков в карточках ссылок — Pillow: `pip install pillow`).
- Node.js и Playwright с Chromium: `npm install -g playwright && npx playwright install chromium` (или локально, лишь бы `require('playwright')` находился).
- MathJax 3 для проверок без интернета: `npm install --prefix textbook/_work/mj mathjax@3`.
- Сами книги открываются в любом браузере; для шрифтов и формул нужен интернет (кроме `optimizers_offline.html`).

## Устройство книги

Каждая книга — один HTML-файл, склеенный скриптом из исходников:

- `b0_gloss.html` — словарь Σ, шапка, оглавление; `b1.html`, `b2.html`, … — разделы текста; `head.part` — `<head>` со стилями;
- `s_*.html` — скрипты рисунков и помощники (холсты рисуются на JS, без библиотек);
- `tools/build.py` — сборка; `tools/*.cjs` — проверки в безголовом Chromium; `NOTES.md` — заметки о главе (карта номеров, отклонения от плана, проверки).
- Глава ∅, часть 1 — исключение: весь текст в `src_ch0p1/ch0_body.part`.

Формулы — TeX внутри `$…$` и `$$…$$`, их рисует MathJax в браузере. Сборка вставляет `<wbr>` после знаков отношения в длинных встроенных формулах
и приклеивает к формуле следующую за ней пунктуацию; исходники остаются чистыми.

## Основной учебник

Скрипты сборки глав писались для рабочей папки с другой раскладкой, поэтому их запускают через `textbook/kit/workspace.py`:
он делает `textbook/_work/` из символических ссылок на исходники (правишь файлы прямо в `textbook/src_*/`), собирает и кладёт готовые страницы в `textbook/*.html`.

```
python3 textbook/kit/workspace.py           # все главы: сборка, указатель перекрёстных ссылок, повторная сборка
python3 textbook/kit/workspace.py nb ang    # только эти главы, один проход
```

Ключи глав: `p1 p2 p3` (∅, части 1–3), `nb` (∇), `ang` (∠), `n1` (𝒩, часть 1). Проверено 30.10.2026: полная сборка из репозитория даёт те же страницы,
что лежат в нём (отличаются только порядок ключей в JSON перекрёстных ссылок и более свежие миниатюры).

**Общий слой оформления** накладывает при сборке `textbook/kit/kit.py`: тёплая светлая тема, круглые кнопки навигации, словаря и темы (`nav.html`, `controls.css`, `tail.html`),
«§» в заголовках, свёртывание подписей (`capfold.html`), кликабельные упоминания (`xref.html`). `fin_scripts.html` — старый общий файл помощников: build.py берёт из него
строки 0–39 (помощники TB) и 418–472 (словарь и свёртывание доказательств).

**Нумерация.**
- Утверждения ∅, ∇, ∠, 𝒩 нумеруются вручную (в тексте прямо стоит «Лемма ∅.15»).
- Новое утверждение в середину главы ∅: `python3 textbook/_work/kit/renum_stmts.py N --apply` (запускать именно через `_work/kit/`: скрипт ищет исходники рядом с рабочей папкой) сдвигает ∅.N и дальше на один во всех главах; потом пересобрать дважды
  и проверить, что каждое упоминание «лемма/теорема ∅.N» совпадает с видом утверждения.
- Рисунки ∅ сквозные через три части: новые подписывать «Рис. ∅.@ключ», затем `python3 textbook/_work/kit/renum_figs.py`. В главе ∇ «Рис. ∇.@ключ» нумерует сам build.py.

**Перекрёстные ссылки.** `kit/xref_index.py` собирает все пронумерованные элементы собранных страниц в `kit/xref_index.json`, и каждая страница встраивает тексты тех чужих элементов,
которые упоминает. Поэтому после изменения текста утверждений нужна полная сборка (два прохода — `workspace.py` без аргументов делает это сам).
Миниатюры рисунков из других частей: `cd textbook/_work && node kit/xref_thumbs.cjs <страницы…>` (PNG в `kit/thumbs/`, `xref_index.py` превращает их в WebP), затем снова `workspace.py`.

**Новая глава или часть:** исходники в `textbook/src_<имя>/` по образцу `src_chAngle/`; добавить её в `CHAPTERS` в `kit/workspace.py`, в `PAGES` в `kit/xref_index.py`,
в `MAIN` и `SHORT` в `kit/hub.py`, обложку — в `kit/hub_covers.cjs`; строку — в таблицу `README.md`.

**Проверки** (из рабочей папки, потому что скрипты ищут MathJax в `./mj`):

```
cd textbook/_work
node kit/chk.cjs nb/ch_nabla.html shots/nb     # кнопки, панели, ошибки MathJax и JS, горизонтальная прокрутка; снимки верха страницы
node kit/figshot.cjs nb/ch_nabla.html shots/f pivot,cusp   # снимки рисунков с этими холстами: 820/390 px, светлая/тёмная тема
node nb/tools/chk.cjs …                         # проверки конкретной главы, см. её NOTES.md
```

Снимки обязательно смотреть глазами (правила о рисунках — в `rules.md` и `FORMAT.md`): ширина 820 и 390 px, обе темы.

## Мини-учебники

```
python3 minibooks/optimizers/tools/build.py      # пишет optimizers.html и optimizers_file.html
MAXSEC=11 python3 minibooks/optimizers/tools/build.py   # только разделы до §11 (пока следующие пишутся)
node minibooks/optimizers/tools/chk.cjs <страница> <путь к tex-svg.js>
```

В мини-учебниках нумерацию делает build.py: `{{Теорема:ключ}}` ставит следующий номер, `{{@ключ}}` — «Теорема N», `{{#ключ}}` — число N, `{{~ключ}}` — сокращение «Теор. N».
`*_file.html` — та же книга с `<!doctype html>`, её удобно открывать с диска и отправлять студентам (в файле без doctype страница идёт в quirks mode).
Офлайн-копия: `python3 minibooks/optimizers/tools/offline.py optimizers_file.html tex-svg.js fonts_inline.css optimizers_offline.html`,
где `fonts_inline.css` — правила `@font-face` из Google Fonts (Literata и др., подмножества cyrillic, latin, greek) с woff2 в виде data-URL, `tex-svg.js` — MathJax 3.2.2.

## Общая страница

```
python3 textbook/kit/hub.py index.html        # из корня репозитория
```

Описания глав и частей написаны вручную в `hub.py`, элементы для поиска берутся из `kit/xref_index.json` и регулярными выражениями из мини-учебника.
Обложки — `kit/covers/*.webp`, делает `kit/hub_covers.cjs` (пути внутри рассчитаны на рабочую папку; поправить при запуске).

## Публикация

Раньше каждая правка книги публиковалась как страница на claude.ai и сразу отправлялась в этот репозиторий. Теперь репозиторий — главный источник.

- После каждого изменения книги — коммит и push прямо в `main`.
- Автор коммита — Ник: `git config user.name "Nikita Vasiliev"`, `git config user.email "99510754+vasiliev-nick@users.noreply.github.com"`.
  Помощник указывается соавтором строкой `Co-Authored-By:` в конце сообщения (Ник согласен). Сообщение коммита — коротко по-английски, что изменилось в книгах.
- Ник иногда правит файлы прямо на GitHub (например, README): сначала `git pull`, его правки не затирать.
- GitHub Pages не предлагать (Ник отказался: читатели скачивают HTML и открывают с диска).
- Лицензии: тексты CC BY 4.0 (`LICENSE`), скрипты MIT (`LICENSE-CODE`).
- Когда меняется состояние работы или появляется новое правило Ника — обновить `CONTEXT/state.md` или `CONTEXT/rules.md` в том же коммите.

## Резервное описание статьи

`notes/backup/paper_backup.md` — исходник, `paper_backup.pdf` — его вёрстка (18 страниц). PDF делался так: защитить `$…$` от Markdown, прогнать python-markdown,
формулы — MathJax SVG, тёплые цвета книг, шрифт Literata (для 𝒩 — FreeSerif), `page.pdf({printBackground: true})` в Playwright.
Скрипт конвертации не сохранился. Обновлять описание после крупных изменений плана, гипотез, постановки прототипа или состояния учебника.
