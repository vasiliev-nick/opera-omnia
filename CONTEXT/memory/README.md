# Память помощника

Выгрузка памяти Claude из проекта «Статья по робототехнике» на 30 октября 2026 года, файлы как есть.
`MEMORY.md` — оглавление, остальные файлы — отдельные записи, связанные ссылками `[[имя]]`. Записи по-английски, короткие, с датами;
каждая отвечает на «что», «почему» (**Why**) и «как применять» (**How to apply**).

Это сырьё: по нему написаны `CONTEXT/rules.md` и `CONTEXT/state.md`, и при расхождении верить им. Пути вида `/mnt/project-files/…` —
это папка проекта Claude; её содержимое лежит в корне этого репозитория (`/mnt/project-files/textbook/` = `textbook/` и т. д.).
Пути `scratchpad/…`, `SP/…`, `nb/…`, `p2/…` — рабочая папка помощника; в репозитории её заменяет `textbook/_work/` (см. `CONTEXT/workflow.md`).
Ссылки на claude.ai/artifact открывает только Ник.
