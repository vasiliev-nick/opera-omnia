## Deviations from the brief

1. **Extra statement.** Fact ∅.39 (Gaussian integral, without proof) is a numbered statement. This shifts the brief's ∅.39–∅.44 to ∅.40–∅.45.
2. **Corollary ∅.31 has an item (г)**: f ≤ g a.e. ⇒ ∫f ≤ ∫g for f, g ≥ 0. Several proofs use it.
3. **Lemma ∅.42 order.** The items are (а) vector spaces, (б) ‖f‖ = 0 ⇔ f = 0 a.e., (в) Cauchy–Bunyakovsky, (г) seminorms, (д) μ(X) = 1. Item (б) moved forward because the proof of (в) uses it.
4. **Theorem ∅.37** is stated for any interval Θ, not only (a,b). Exercise ∅.7 needs Θ = [0,b).
5. **Exercise ∅.5(б).** The brief's "no subsequence converges pointwise anywhere" is impossible: at any single point some subsequence converges. The exercise instead asks to prove that no subsequence converges on a set of positive measure. The example is f_n = 2 × (n-th binary digit).
6. **Exercise ∅.8.** "No inclusion holds on an infinite measure space" is false in general: for counting measure on ℕ, ℒ¹ ⊂ ℒ². The claim is stated for (ℝ, λ₁), and a remark covers counting measure.
7. **CSS added to the head copy:**
   - `.seg` (mode buttons);
   - `.modes`, with a portrait variant under 600 px;
   - `.controls [hidden]` (part 1's `label{display:flex}` overrode `hidden`);
   - `.nw`.

   I also changed `.math-wrap` to `display:block`. In part 1 it is an inline span, so `overflow-x:auto` does nothing and wide display formulas push the whole page sideways on a phone. Part 1 has this bug too: its page is 510 px wide in a 390 px viewport.
8. **«В 3D»** reuses part 1's `.d3` dashed box (`id="in3d"`). No `.in3d` class was needed.
9. **Canvases are responsive.** A new block after the copied TB block adds `TB.fit`, `TB.onResize`, `TB.rich`, `TB.legend`, `TB.segs` and `TB.rows`. Each canvas redraws at the column width with devicePixelRatio, and has a legend row drawn on the canvas. Part 1's canvases draw at a fixed 760 px and scale down, so on a phone their labels end up around 6 px (`shots/p1m_*.png`).
10. **Build-time typesetting.** `build.py` makes two changes:
    - it inserts `<wbr>` after top-level relations (=, ≤, →, …) in long inline formulas, which is TeX's own line-breaking rule for running text;
    - it glues trailing punctuation to its formula with `span.nw`.

    Without these, single inline formulas overflowed a 390 px viewport and periods wrapped to the start of the next line. The sources in `src/` stay clean.
11. **Рис. ∅.13 gauge.** It uses a compactified scale v/(1+v) with ticks 1, 2, 4, 9 and +∞, so the divergence 1 + ln n is visible. The caption explains the scale.
12. **Рис. ∅.14 inf.** The infimum is exact without a horizon cut. f_n = (1−a_n)P_{n mod 3} increases within each residue class, so g_n = min(f_n, f_{n+1}, f_{n+2}). The caption says this.
13. **Рис. ∅.15** has an ε-threshold slider (S mode only) and a second gauge, sup|f_n − f|. The gauge shows that the convergence is not uniform, so the DCT is really needed.

## Doubts

- **Eyebrow.** The brief asks for "Часть 2 из 3", but part 1 still says "Часть 1 из 2", so part 1's eyebrow needs updating.
- **Wide display formulas on phones.** About a dozen are 5–60 % wider than a 390 px column. They now scroll inside their own box. The two widest (the set identity in Def ∅.29 and Minkowski in Lemma ∅.42) were split into two lines, and the gradient bound in the 3D box was split too. A further pass could break the rest.
- **Probe input.** Рис. ∅.16 uses `touch-action: pan-y`: horizontal drags move the probe, vertical swipes still scroll the page. Part 1's dyadic figure uses `none`.
- **Glossary scope.** It lists 𝔻ξ, which is introduced only in Exercise ∅.6. Drop it if the glossary should cover the main text only.
- **Forward reference.** The sign-condition remark after Fatou says ∫ sup_{k≥n} k·1_(0,1/k) = ∞ "как будет видно в начале §∅.9". It is a forward reference to a computation, not to an undefined notion.
